# 일본 신고가 근접 · 시총 상위 페이지

스크롤(또는 방향키)로 넘기며 보는 한 장짜리 페이지입니다.
주소: `https://<계정>.github.io/<리포이름>/`

## 데이터는 두 파일에 들어 있습니다

| 파일 | 내용 | 갱신 |
|---|---|---|
| `data/companies.json` | 종목 목록, 소개, 최근 6개 분기 실적 | 실적 시즌마다 새 파일로 교체 |
| `data/prices.json` | 최근 1년 주봉 종가, 현재가, 52주 고가 | 필요할 때 새 파일로 교체 |

두 파일 모두 리포의 `data` 폴더에 같은 이름으로 올리면 덮어써지고, 1~2분 뒤 페이지에 반영됩니다.

## 알아둘 점

- 주가는 자동으로 갱신되지 않습니다. 무료 시세 소스(야후, Stooq)가 GitHub 서버의 요청을 막고,
  TradingView 임베드 차트는 도쿄 종목을 허용하지 않기 때문입니다. 화면에 주가 기준일이 표시됩니다.
- `pipeline/build.py` 와 `.github/workflows/update.yml` 은 더 이상 쓰지 않습니다.
  Actions 탭 → update-prices → 오른쪽 `⋯` → Disable workflow 로 꺼 두세요.
- GitHub Pages 주소는 링크를 아는 사람이면 누구나 열 수 있습니다. 검색엔진 수집은 막아 두었습니다(noindex).
- 특정 종목으로 바로 가는 링크: 주소 뒤에 `#co-종목코드` (예: `#co-9983`).
- 시총은 2026-11-20 스냅샷에 주가 변동률을 곱한 추정치입니다.
- 1개월·3개월·1년 수익률은 각각 4·13·52주 전 주간 종가 대비입니다.
- 매출비중 문구는 근사치입니다. 분기 실적과 주봉은 株探(kabutan) 기준입니다.
